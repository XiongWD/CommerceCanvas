# CommerceCanvas 前端体验原型验收清单

> 版本：0.1.0  
> 用途：Codex/人工验收前端原型，防止开发 Agent 只交付“能运行”的普通后台页面。

## A. 文档与范围

- [ ] 已列出适用的 FD、NG 和 OD 编号。
- [ ] 未把 `VALIDATION_REQUIRED` 写成已验证能力。
- [ ] 未实现 G2 明确排除的后端、数据库或真实 Provider。
- [ ] 未私自关闭开放决策。
- [ ] 所有演示数据明确标记为演示数据。

## B. 中文客户体验

- [ ] 导航、按钮、标题、空状态为简体中文。
- [ ] 分析轨迹、警告、错误、里程碑为简体中文。
- [ ] 质量策略使用“快速、均衡、高质量、商品保真优先、文字准确优先”。
- [ ] Provider ID、Model ID 等英文标识旁有中文解释。
- [ ] 普通客户界面没有英文原始日志、堆栈和 Worker stdout。
- [ ] 术语与 `glossary.md` 一致。

## C. Graphite Canvas

- [ ] 中央媒体画布是视觉重心。
- [ ] 全局栏、上下文栏、属性检查器和底部状态栏比例合理。
- [ ] 页面不像 ERP 或 KPI Dashboard。
- [ ] 没有大面积白色背景、紫色渐变、玻璃拟态和卡片堆叠。
- [ ] 蓝色用于选中和主操作。
- [ ] 紫色仅用于 AI/演算能力。
- [ ] 绿色、黄色、红色分别表达通过、待检查和失败/阻断。
- [ ] 等宽字体只用于 ID、时间、事件码和指标。

## D. 实时智能演算层

- [ ] 开始任务后立即出现可理解状态。
- [ ] 分析轨迹是业务语义，不是开发日志。
- [ ] 事件至少区分发现、依据、决策、警告、动作、产物和里程碑。
- [ ] 事件顺序稳定。
- [ ] 重放事件不会重复展示。
- [ ] 断线恢复状态可演示。
- [ ] 未知总量不显示伪百分比。
- [ ] 高频事件不会造成界面闪烁和滚动失控。
- [ ] 用户切换页面后活动任务仍可见。
- [ ] 任务结束后轨迹和证据可复查。

## E. 证据和中间结果

- [ ] 关键分析发现能定位到对应图片或区域。
- [ ] OCR 框、Logo 框、商品 Mask 等可独立开关。
- [ ] 中间 Artifact 在任务结束前可预览。
- [ ] Creative Recipe 会逐步形成，而不是结束后突然出现。
- [ ] QC 结果能指出风险区域和失败原因。
- [ ] 路由升级、重试和成本变化有中文原因说明。
- [ ] 视觉效果没有伪造不存在的模型能力或思考过程。

## F. 页面覆盖

- [ ] 竞品套图分析是首个完整高质量页面。
- [ ] Job Detail 可以查看节点、事件、产物、QC 和成本。
- [ ] Product Workspace 展示 Product Master 关键身份信息。
- [ ] Generate Studio 展示质量策略、成本和 QC 淘汰。
- [ ] Localization Studio 展示 OCR、保护字段和排版风险。
- [ ] Review Room 展示版本、证据和返工。
- [ ] Work Queue 展示任务状态、人工介入和恢复情况。

## G. 工程证据

- [ ] 提供实际运行命令。
- [ ] `npm run build` 实际通过。
- [ ] 单元测试实际通过。
- [ ] Playwright 关键流程实际通过。
- [ ] 提供 1440×900 页面截图。
- [ ] 提供正常、警告、断线恢复三种录屏或截图序列。
- [ ] 提交已知缺陷清单。
- [ ] 未使用“应该通过”“理论上可用”代替真实执行证据。
