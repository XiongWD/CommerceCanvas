# 演示素材来源与许可说明（G2-F0）

> 用途：记录 `frontend/public/demo-assets/` 下演示商品素材的来源、许可与使用边界。
> 这些素材仅用于 G2 前端原型的高保真视觉验收，不代表真实竞品图片，也不含任何品牌、Logo、型号或可识别商业标识。

## 1. 素材清单

| 文件 | 用途角色 | 内容描述 |

| `scene-main-01.svg` | 主图 | 开放式头戴耳机，右侧主体 / 左侧文案构图，深灰工作场景 |

## 2. 来源与许可

- **来源**：本仓库自行制作的矢量素材（SVG），由开发 Agent 在 G2-F0 R1 阶段原创绘制。
- **制作方式**：纯 SVG 手写，使用渐变、几何形状与占位块，**未引用任何第三方图片、未抓取任何竞品素材、未使用任何 AI 生成服务**。
- **许可**：随本项目仓库一并分发，无第三方版权约束。
- **无品牌声明**：所有素材均不含 Logo、型号、包装文字、可识别商业标识或真实产品外观。
- **不依赖远程 URL**：全部以本地文件形式存放于 `public/demo-assets/`，由 Vite 静态服务，无任何外链。

## 4. 使用边界

- 这些素材**仅为演示**，标注为「演示素材」与「模拟分析结果」。
- 证据框（商品主体 / Logo 风险 / 安全区 / 构图辅助线）叠加在真实演示素材之上，是模拟分析结果，不来自真实模型。
- 生产环境必须替换为经法律与策略审查的真实素材（OD-009）。
